# Anamnese de Psicologia — perguntas para você decidir

Estas são as decisões que só você, como psicóloga, pode tomar. Pode responder no detalhe que
quiser — pode escrever ao lado, gravar um áudio, ou só marcar. Não existe resposta errada: o
objetivo é o sistema ficar do **seu** jeito de trabalhar. Sem pressa.

Se alguma pergunta não fizer sentido, escreve "não se aplica" e segue.
